# Maze Off

Neon/Tron «побег из тёмного лабиринта» на **Godot 4.7 / GDScript**.
Свет — ресурс и главный нерв: он тает всё время, а темнота прячет и выход,
и того, кто идёт за тобой.

**Всё в игре процедурное.** `main.tscn`, `menu.tscn`, `player.tscn` — заглушки
в один узел; мир, стены, свет, HUD, текстуры и звуки строятся кодом. Чтобы
что-то изменить, правишь `.gd`, а не сцену. Ассетов-картинок нет вообще.

## 🎮 Режимы игры

| Режим | Что это | Прогресс |
|-------|---------|----------|
| **Уровни** | Кампания на 50 уровней. Выход не заперт — **не известно, где он**; осколки дают улики, сужающие поиск | Копится навсегда, навыки за SP |
| **Накал** | Рогалик-спуск без дна. 3 слота, 3 жизни на весь забег; несомый «накал» можно потерять или забанковать на алтаре | Каждый забег с нуля |
| **Спуск дня** | Один лабиринт на всех (сид от даты), одна попытка в сутки, серия дней | Отдельная история |
| **Логово** | 10 уровней, в центре — тронный зал с владыкой тьмы | Своя лестница |
| **Пещеры** | 20 уровней, лабиринт — не сетка, а граф комнат с извилистыми ходами | Своя лестница |
| **Обучение** | 3 коротких этапа, проиграть невозможно | — |

**Сложность** (Тлеющий / Горящий / Пылающий) — общий переключатель. На
Пылающем **станций нет вовсе**: свет только из осколков.

## ▶️ Запуск

Godot **не в PATH**. Пути по машинам:

```bash
# Windows (эта машина): ПАПКА с именем .exe, внутри — консольный exe
GODOT="/c/Users/Admin/Desktop/Godot_v4.7.2-stable_win64.exe/Godot_v4.7.2-stable_win64_console.exe"
```

Запустить игру (меню → Играть):

```bash
"$GODOT" --path .
```

Сразу в геймплей, минуя меню:

```bash
"$GODOT" --path . res://main.tscn
```

После добавления любого `.mp3`/`.wav`/`.png` — импорт, иначе `load()` вернёт `null`:

```bash
"$GODOT" --headless --import --path .
```

### Проверка (юнит-тестов и линтера нет)

Одна команда на всё — `tools/verify.sh` (bash) или `tools/verify.bat` (Windows без
bash): смоук + играбельность всех режимов (`tools/verify.gd`) + сверка хэшей
сейвов до/после. Пустой вывод смоука = всё в порядке.

```bash
"$GODOT" --headless --path . res://main.tscn --quit-after 90 2>&1 | grep -iE "error|SCRIPT|parse|invalid|nonexistent" | grep -viE "resources still|audio"
```

Смоук сам по себе гоняет **только режим Уровни**; `verify.gd` добирает
остальные режимы (Накал, Спуск дня, Логово, Пещеры, обучение + спецпроверки
арены/спавна). Меню и визуал проверяются одноразовыми харнессами, которые
пишутся под задачу и **удаляются после**. Подробности и правила безопасности
сохранения — в CLAUDE.md.

⚠️ **Харнессы могут затереть реальный сейв** (`user://maze_off.cfg`) — это уже
случалось. Перед оконным прогоном делай резервную копию. См. CLAUDE.md,
раздел про `test_mode`.

## ⚖️ Три правила, которые ломались чаще всего

1. **Не коммитить без явного разрешения.** Разрешение одноразовое: следующая
   правка требует нового.
2. **Смена размеров сетки инвалидирует точку входа.** Любой код, меняющий
   `_cols`/`_rows`, обязан заново выставить `_entry_cell` — иначе игрок
   появляется в пустоте. Шипилось трижды.
3. **Пороги уровней — только в `GameConfig.LADDER`**, частота механики — только
   в правилах биома. Никаких новых `*_FROM_LEVEL` и `*_CHANCE` констант.

Полный список — в CLAUDE.md. Он не «документация ради документации»: каждый
пункт там появился после реального бага.
